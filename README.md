# 隊列インカム

複数台で連なって走るときのための、軽いWebインカム＋車間距離メーターです。
ブラウザで開くだけで使え、アプリのインストールもアカウント登録も要りません。

- 前後の車との**直線距離**と**遅れ時間**を大きく表示
- ワンタップの**定型ボイス**（相手側で通知音と読み上げ）
- 押している間だけ話せる**トランシーバー通話**
- 隊列順（1号車・2号車…）の共有と入れ替え

通話をつなぎっぱなしにしないので、常時通話より電池と通信量を抑えられます。

## 使い方

1. 公開URLをスマホのブラウザで開く（iPhoneはSafari、AndroidはChrome）。
2. 名前を入れ、「新規作成」でルームコードを作って「参加する」。
3. 「位置情報」と「マイク」を許可する。
4. 「招待」から仲間を呼ぶ。全員が同じルームコードで参加すればつながります。

### 招待のしかた

「招待」を押すと次の方法が選べます。リンクを開いた人はルームコードが入力済みなので、名前を入れるだけです。

| 方法 | 向いている場面 |
|---|---|
| QRコード | その場にいる人。カメラで読み取るだけ |
| LINEで送る | 離れている人。LINEの送信先選択が開きます |
| リンクをコピー | ほかのアプリで送りたいとき |

### 画面の見かた

- **隊列**：前から順に1号車・2号車…と並びます。自分の前後の車との距離が大きく表示されます。
- **遅れ時間**：後ろ側の車が今の速度で前の車の位置に着くまでの時間です。停車中は表示されません。
- **▲ 前に出た／▼ 後ろに下がった**：自分の順番を入れ替えます。全員の画面に反映されます。
- **定型文ボタン**：押すと全員に送られます。「設定」から自分用に書き換えられます（各20文字まで、端末ごとに保存）。
- **話す**：押している間だけ送話。短くタップすると20秒間固定され、もう一度タップで終了します。

## 注意と制約

- **運転者は走行中に操作しないでください。** 同乗者が操作するか、停車中に使ってください。
- **画面は点けたまま、このページを前面に。** 画面を消したり他のアプリに切り替えたりしている間は、位置共有も通話も止まります（ブラウザの制約）。充電しながらの使用を推奨します。
- **距離は直線距離です。** 道のりではないので、つづら折りなどでは短めに出ます。
- **マイクは参加中ずっと開いています**（送話していない間は無音を送ります）。
- **最大6台**まで。
- **LINEなどのアプリ内ブラウザでは、マイクや位置情報が使えないことがあります。** 標準ブラウザで開いてください。

## 途切れたとき

次の場合は自動で元のルームに戻ります。

- 画面オフや他のアプリから戻ったとき
- 電波が切れて戻ったとき
- タブが落ちた・再読み込みしたあとにページを開き直したとき（12時間以内、自分で「退出」していない場合。号車の順番も引き継ぎます）

赤い「ここをタップして音声を再開」の帯が出たら、画面のどこかを1回タップしてください。

それでもつながらない場合は、ページの再読み込み、または Wi-Fi を切って携帯回線に切り替えると改善することがあります。

## しくみ

- 単一のHTMLファイルで、専用サーバーはありません。GitHub Pages などの静的ホスティングに置くだけで動きます。
- 参加者同士の引き合わせには [PeerJS](https://peerjs.com/) の無料公開サーバーを使い、つながった後の音声と位置情報は端末同士が直接（WebRTC）やり取りします。
- 無料の公開サーバーに依存しているため、稼働は保証されません。回線の組み合わせによっては端末同士がつながらないことがあります。

## プライバシー

- 位置と音声が届くのは、同じルームコードで参加している相手だけです。ルームコードは仲間内だけで共有してください。
- 位置や音声をサーバーに保存する処理はありません。
- 名前・前回のルームコード・定型文は、その端末のブラウザ内にだけ保存されます。

## 自分で公開する（GitHub Pages）

1. GitHubで Public のリポジトリを作る。
2. `convoy-intercom.html` を `index.html` という名前でアップロードする。
3. Settings → Pages で Branch を `main` / `(root)` にして Save。
4. 1〜2分後に表示される `https://<ユーザー名>.github.io/<リポジトリ名>/` が公開URLです。

位置情報とマイクはHTTPSが必須ですが、GitHub Pagesなら満たします。

## 机上テスト

URLの末尾に `?sim=1` を付けると擬似GPS（時速54kmで北上）で動きます。同じルームを2つのタブで開けば、車を走らせずに車間表示まで確認できます。
